# Eventra — HCI Plan

HCI is the central objective of this project. Features should be justified by user needs and evaluated through usability, not added only to increase the feature count.

## HCI principles to apply

### 1. Visibility of system status
Show clear loading, booking confirmation, saved/favourite state, ticket availability, and error feedback.

### 2. Match between system and the real world
Use familiar event terminology: date, venue, organiser, ticket, price, and booking reference.

### 3. User control and freedom
Allow users to change filters, remove favourites, edit ticket quantity before confirmation, and cancel simulated bookings where appropriate.

### 4. Consistency and standards
Use consistent buttons, typography, spacing, icons, navigation patterns, and feedback across screens.

### 5. Error prevention and recovery
Validate required event information, prevent invalid ticket quantities, explain errors clearly, and preserve user input when possible.

### 6. Recognition rather than recall
Show event images, categories, dates, locations, saved events, and booking details instead of making users remember information across screens.

### 7. Accessibility
Use readable text, sufficient contrast, large touch targets, meaningful labels, and avoid communicating status through colour alone.

## Usability testing

Test with several people who were not involved in development.

Ask participants to:
1. Find an event in a chosen category.
2. Find an event within a specified price range.
3. Save an event and find it later.
4. Book two tickets.
5. Find their booking reference.

Observe:
- Task completion
- Time taken
- Errors and backtracking
- Requests for help
- User confidence and satisfaction

Record findings, prioritise problems, make changes, and test again.

## Evidence for the final report

Keep:
- User interview notes (with consent)
- Personas based on actual research
- User journeys
- Wireframes and prototypes
- Design decisions and rationale
- Usability test tasks and findings
- Before/after screenshots showing improvements
