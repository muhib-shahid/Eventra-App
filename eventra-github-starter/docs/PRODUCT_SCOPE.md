# Eventra — Product Scope

## Problem statement

People often discover events through scattered social posts, posters, and messaging groups. Important details such as date, venue, price, availability, and booking instructions can be difficult to compare or find later.

Eventra brings event discovery and booking into one coherent mobile experience.

## Target users

### Primary: Event attendees
People who want to discover events, compare details, save interesting events, and manage their bookings.

### Secondary: Event organizers
People or organisations that need to publish event information and manage attendee bookings.

## Core user journeys

### Attendee
1. Open the app and browse featured or upcoming events.
2. Search or filter by category, date, location, or price.
3. Open an event and inspect its details.
4. Select a ticket quantity.
5. Review and confirm the booking.
6. Find the booking later in My Tickets / Bookings.

### Organizer
1. Open the organizer area.
2. Create an event with title, description, category, date, venue, price, capacity, and cover image.
3. Preview and publish the listing.
4. Edit or unpublish the event.
5. Review bookings.

## MVP (must work)

- Browse event listings
- Search events
- Filter by category
- View event details
- Save and remove favourites
- Select ticket quantity
- Create a booking (initially simulated; no real payment processing)
- View booking history

## Later enhancements

- Authentication
- Organizer accounts and event management
- Location-aware discovery
- Push notifications
- QR-code ticket display / check-in simulation
- Reviews and ratings
- Calendar integration

## Out of scope for the initial university prototype

- Real payment gateway
- Legally binding ticket issuance
- Real-world identity verification
- Complex refund and financial settlement systems

## Success criteria

A first-time user should be able to:
- Find an event using search or filters.
- Understand the essential event information.
- Complete a sample booking without assistance.
- Locate the booking afterward.
- Recover gracefully from invalid or incomplete input.
